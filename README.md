🏃‍♂️ Athlete Heart Rate Zone Calculator & Visualizer

A vibrant, highly stylized Python-based graphical user interface (GUI) designed for student-athletes and endurance runners to quickly compute personalized training zones. Built using `tkinter`, this tool calculates metabolic training ranges using the medically acclaimed Karvonen Formula, factoring in both chronological age and resting heart rate (RHR).

Designed with a high-contrast cyberpunk and punk-pop aesthetic inspired by contemporary streetwear identity (featuring neon lime, hot pink, and deep midnight tones), this application demonstrates a strong synergy between backend algorithmic computation and front-end UI/UX layout engineering.

🚀 Key Features

*   Dynamic Karvonen Calculations: Computes individual aerobic, anaerobic, and VO2 Max thresholds with high statistical accuracy instead of relying on generic maximum heart rate predictions.
*   Custom Geometric UI Overlays: Utilizes custom-rendered pixel-mapped canvas polygons to build sleek, border-radius independent components, ribbon banners, and oval encapsulation modules.
*   Responsive Error Catching: Includes strict string-to-integer conversion sanitation safeguards to prevent core thread routine interruption upon user data mistyping.
*   Welcome Page Overlay Stack: Implements a layered software layout architectural pattern allowing a splash configuration view to fully clear out upon application instantiation.

🧮 Algorithmic Methodology (The Karvonen Formula)

Generic fitness tracking engines estimate your intensity ranges solely by deducting your age from 220. This software utilizes a deeply personalized biometric layer:

\[\text{HR}_{\text{target}} = \left((\text{HR}_{\text{max}} - \text{HR}_{\text{resting}}) \times \text{Intensity}\%\right) + \text{HR}_{\text{resting}}\]

Where:
*   \(\text{HR}_{\text{max}} = 220 - \text{Age}\)
*   \(\text{Heart Rate Reserve (HRR)} = \text{HR}_{\text{max}} - \text{HR}_{\text{resting}}\)

  bash
